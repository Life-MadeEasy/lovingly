# LOVINGLY — Landing Page

Production-ready vanilla HTML/CSS/JS implementation of the LOVINGLY premium digital celebration studio landing page.

## Files
- `index.html` — semantic HTML, SEO metadata, Open Graph/Twitter cards, JSON-LD
- `styles.css` — responsive editorial visual system
- `script.js` — mobile navigation, FAQ accordion, reveal animation, WhatsApp CTA
- `favicon.svg` — lightweight inline SVG favicon

## Before launch
1. Replace `919999999999` in `script.js` with the production WhatsApp number.
2. Replace `Privacy Policy` and `Terms` placeholder hrefs with real URLs/pages.
3. Add the real `https://lovingly.in/og-image.jpg` asset.
4. Confirm the demo URL `https://lovingly.in/aarav-diya` is live.
5. If the final brand has a real Instagram URL, update the footer link.
6. Self-host fonts or use a production-approved font delivery strategy if desired.

No stock photography or UI libraries are required. The visual product previews are built entirely with HTML/CSS, keeping the initial page lightweight.
